**核心依赖纪律**：
- 所有系统通过 `EventBus` 解耦，不直接互相引用
- `ModifierPipeline` 是伤害计算的唯一聚合点，Buff/词条/遗物/元素都往里注入 Modifier
- `DataService` 是数据查询的唯一入口，不绕过它直接 LoadAsset
- `ObjectPool<T>` 是所有高频对象（敌人/弹道/特效/伤害数字）的唯一创建/回收通道

### 2.1 EventBus（全局事件总线）

```
命名空间：CryptWalker.HotUpdate.Core
位置：HotUpdate/Scripts/Core/EventBus.cs
```

**设计目标**：系统间解耦通信。受击、击杀、升级、拾取等事件通过总线广播，监听方按需订阅。

```csharp
// 事件基类
public abstract class GameEvent { }

// 示例事件
public class EntityHitEvent : GameEvent {
    public EntityBase attacker;
    public EntityBase target;
    public float damage;
    public EElementType element;
    public bool isCrit;
}
public class EntityKillEvent : GameEvent {
    public EntityBase killer;
    public EntityBase victim;
    public int expReward;
    public int goldReward;
}
public class LevelUpEvent : GameEvent {
    public int newLevel;
}
public class WeaponSwapEvent : GameEvent {
    public int slotIndex; // 0 or 1
}

// 总线
public static class EventBus {
    // 订阅
    public static void Subscribe<T>(Action<T> handler) where T : GameEvent;
    // 取消
    public static void Unsubscribe<T>(Action<T> handler) where T : GameEvent;
    // 发布
    public static void Publish<T>(T evt) where T : GameEvent;
    // 清空（切场景时调用）
    public static void Clear();

```

**内部实现**：`Dictionary<Type, List<Delegate>>`，Publish 时遍历调用。无队列，同步执行。

### 2.2 ModifierPipeline（伤害聚合管道）

```
命名空间：CryptWalker.HotUpdate.Combat
位置：HotUpdate/Scripts/Combat/ModifierPipeline.cs
```

**设计目标**：策划案三.3 要求"全部加成走统一 Modifier 聚合管道，避免数值漏算/多算"。Buff/词条/遗物/元素都将自己的 Modifier 注入管道，伤害计算时一次性聚合。

```csharp
// Modifier 快照：某一次攻击时的全部加成聚合
public struct DamageModifier {
    // 百分比加成
    public float attackPct;        // 攻击力 +%
    public float critRate;         // 暴击率
    public float critMult;         // 暴击倍率
    public float pierce;           // 穿透
    public float lifesteal;         // 吸血
    // 固定加成
    public float flatAtk;          // 攻击力 +固定值
    // 特殊标记
    public bool isCrit;            // 本次是否暴击（Roll 后确定）
    // 元素附伤
    public Dictionary<EElementType, int> elementBonus;
}

// 管道：收集所有来源的 Modifier
public static class ModifierPipeline {
    // 注册一个 Modifier 来源（Buff/词条/遗物各自注册）
    public static void RegisterProvider(IModifierProvider provider);
    public static void UnregisterProvider(IModifierProvider provider);
    // 聚合：返回当前快照
    public static DamageModifier Build(WeaponConfig weapon);
}

// 来源接口
public interface IModifierProvider {
    void Contribute(ref DamageModifier mod, WeaponConfig weapon);
}
```

**聚合流程**（对应策划案公式）：
```
1. 新建空 DamageModifier
2. 遍历所有 IModifierProvider.Contribute() — Buff/词条/遗物各自填值
3. Roll 暴击：Random < critRate → isCrit=true
4. 返回快照给 DamageCalc 计算最终值
```

### 2.3 DamageCalc（伤害计算）

```
位置：HotUpdate/Scripts/Combat/DamageCalc.cs
```

```csharp
public static class DamageCalc {
    public static float Calculate(
        WeaponConfig weapon,
        EnemyBase target,
        DamageModifier mod
    ) {
        // 策划案公式：
        // 最终伤害 = (基础攻击 × 武器倍率 × (1+攻击加成%) + 固定附加)
        //           × 暴击倍率(若触发)
        //           × 防御减伤系数
        //           × 随机浮动 0.95~1.05
        float atk = weapon.baseAttack * GetWeaponMultiplier(weapon)
                   * (1f + mod.attackPct) + mod.flatAtk;
        float crit = mod.isCrit ? mod.critMult : 1f;
        float defFactor = GetDefFactor(target.Defense, mod.pierce);
        float roll = Random.Range(0.95f, 1.05f);
        return atk * crit * defFactor * roll;
    }

    static float GetWeaponMultiplier(WeaponConfig w) => w.weaponType switch {
        EWeaponType.Melee  => 1.0f,   // 长剑
        EWeaponType.Ranged => 1.3f,   // 长弓（蓄满 2.0 在弓类内处理）
        EWeaponType.Spell  => 1.2f,   // 法杖
        _ => 1.0f,
    };

    // 减伤系数 = 敌防 / (敌防 + 玩家攻击×穿透)，上限 50%
    static float GetDefFactor(float def, float pierce) {
        float factor = def / (def + pierce + 0.01f);
        return Mathf.Clamp01(factor); // 0~1，减伤越多 factor 越接近 1
    }
}
```

### 3.4 EnemyBase + FSM

```csharp
public class EnemyBase : EntityBase {
    protected StateMachine<EnemyBase> _fsm;
    public EnemyConfig Config;   // SO 数据

    public float SightRange = 6f;     // 视野半径（格）
    public float AttackRange = 1.5f; // 攻击半径（格）

    public override void OnSpawn() {
        _fsm = new StateMachine<EnemyBase>(this);
        _fsm.ChangeState<IdleState>();
    }

    public void Tick() => _fsm.Tick();

    // 状态转换优先级：Death > Hit > Attack > Chase > Patrol > Idle
    public bool CanSeePlayer() => DistanceToPlayer() < SightRange;
    public bool InAttackRange() => DistanceToPlayer() < AttackRange;
}
```

### 3.5 状态机框架

```csharp
// 策划案推荐的泛化 FSM
public abstract class EnemyState<T> where T : EnemyBase {
    protected T self;
    protected StateMachine<T> fsm;
    public abstract void OnEnter();
    public abstract void OnUpdate();
    public abstract void OnExit();
}

public class StateMachine<T> where T : EnemyBase {
    private EnemyState<T> _current;
    private T _owner;

    public void ChangeState<S>() where S : EnemyState<T> {
        _current?.OnExit();
        _current = (S)Activator.CreateInstance(typeof(S), _owner);
        _current.OnEnter();
    }
    public void Tick() => _current?.OnUpdate();
}
```

### 3.6 六个基础状态

| 状态类 | OnEnter | OnUpdate | OnExit |
| :--- | :--- | :--- | :--- |

| `PatrolState` | 选随机目标点 | 向目标移动；检测玩家 → Chase | — |
| `ChaseState` | 1.2×速度追玩家 | 出视野 8 格 → Idle；进攻击范围 → Attack | — |
| `AttackState` | 播攻击动画 | 动画事件触发伤害判定；结束 → Chase | — |
| `HitState` | 受击后仰 0.2s 硬直 | 计时结束 → Chase | — |
| `DeathState` | 播死亡动画 | 动画结束 → 掉落物 + 对象池回收 | — |

public class Projectile : MonoBehaviour, IPoolable {
    public float Speed;
    public float Range;          // 最大飞行距离
    public int PierceCount;      // 穿透次数（词条 piercing）
    public DamageModifier Mod;  // 携带的 Modifier 快照
    public EElementType Element;
    public LayerMask HitMask;    // 碰撞层过滤

    Vector2 _startPos;
    int _hitCount;

    void Update() {
        // 移动
        transform.position += (Vector3)Direction * Speed * Time.deltaTime;
        // 超射程 → 回收
        if (Vector2.Distance(_startPos, transform.position) > Range)
            ObjectPoolManager.Return(this);
    }

    void OnTriggerEnter2D(Collider2D other) {
        // 命中敌人 → DamageCalc → TakeDamage
        // 穿透判定
        if (++_hitCount > PierceCount)
            ObjectPoolManager.Return(this);
    }

    public void OnSpawn() { _hitCount = 0; }
    public void OnRecycle() { }
}

### 5.1 元素印记组件（挂敌人身上）

```csharp
public class EnemyElementMarks : MonoBehaviour {
    // 最多 2 种印记（策划案修正后规则）
    private Dictionary<EElementType, float> _marks = new();
    // 元素反应内置 CD
    private float _reactionCooldown;

    public bool HasMark(EElementType e) => _marks.ContainsKey(e);
    public float GetMarkTimer(EElementType e) => _marks.TryGetValue(e, out var t) ? t : 0;

    // 附着规则：上限 2 枚，第 3 种看能否组有效反应
    public bool CanApply(EElementType e) {
        if (_marks.Count < 2) return true;
        if (_marks.ContainsKey(e)) return true; // 已有同元素 → 刷新计时
        // 第 3 种：仅当能与剩余一枚组成有效反应时才顶替
        foreach (var existing in _marks.Keys)
            if (ElementReactionTable.IsValidReaction(existing, e))
                return true;
        return false;
    }

    public void AddMark(EElementType e, float duration = 5f) {
        if (!CanApply(e)) return;
        // 如果第 3 种且能反应 → 先移除不参与反应的旧印记
        if (_marks.Count >= 2 && !_marks.ContainsKey(e))
            RemoveNonReactingMark(e);
        _marks[e] = duration;
    }

    void Update() {
        // 计时衰减
        var expired = new List<EElementType>();
        foreach (var kv in _marks) {
            _marks[kv.Key] = kv.Value - Time.deltaTime;
            if (_marks[kv.Key] <= 0) expired.Add(kv.Key);
        }
        foreach (var e in expired) _marks.Remove(e);

        // 反应 CD
        if (_reactionCooldown > 0)
            _reactionCooldown -= Time.deltaTime;

        // 检测反应（0.5s 内冷却）
        if (_reactionCooldown <= 0)
            ElementReactionTable.TryTrigger(this);
    }
}
```

### 5.2 反应表（配置化）

```csharp
public static class ElementReactionTable {
    // 有效反应对
    private static readonly HashSet<(EElementType, EElementType)> _validPairs = new() {
        (Fire, Ice), (Fire, Thunder), (Ice, Thunder), (Fire, Poison),
    };

    public static bool IsValidReaction(EElementType a, EElementType b) {
        return _validPairs.Contains((a, b)) || _validPairs.Contains((b, a));
    }

    // 检测并触发反应
    public static void TryTrigger(EnemyElementMarks marks) {
        var list = new List<EElementType>(marks._marks.Keys);
        for (int i = 0; i < list.Count; i++)
            for (int j = i + 1; j < list.Count; j++) {
                if (IsValidReaction(list[i], list[j])) {
                    TriggerReaction(marks, list[i], list[j]);
                    marks._reactionCooldown = 0.5f; // 内置 CD
                    return; // 一次只触发一个反应
                }
            }
    }

    static void TriggerReaction(EnemyElementMarks marks, EElementType a, EElementType b) {
        // 策划案四种反应：
        // 火+冰 → 蒸汽爆炸（半径3，攻击×1.8，致盲2s）
        // 火+雷 → 过载爆发（半径4，攻击×2.2，击退3格）
        // 冰+雷 → 感电连锁（攻击×1.2，链5敌）
        // 火+毒 → 剧毒爆燃（已损生命×25%）
        // 反应触发后清除参与反应的两枚印记
        marks._marks.Remove(a);
        marks._marks.Remove(b);
        // 通过 EventBus 广播 ReactionEvent → AOE/连锁/击退逻辑
    }
}
```

public class InventorySystem {
    // 双武器槽位

    // 切换硬直
    public bool IsSwapping { get; private set; }
    private float _swapTimer;
    private const float SwapDuration = 0.3f;

    // 词条跨武器规则：
    //   主动类词条（攻速/暴击/元素附伤）仅对当前武器生效
    //   被动类词条（击杀重置/吸血/分裂）全局生效

    public void Swap() {
        if (IsSwapping) return;
        ActiveSlot = 1 - ActiveSlot;
        IsSwapping = true;
        _swapTimer = SwapDuration;
        EventBus.Publish(new WeaponSwapEvent { slotIndex = ActiveSlot });
    }

    public void Tick() {
        if (IsSwapping) {
            _swapTimer -= Time.deltaTime;
            if (_swapTimer <= 0) IsSwapping = false;
        }
    }

    public WeaponBase ActiveWeapon => Weapons[ActiveSlot];
}

```csharp
public interface IPoolable {
    void OnSpawn();
    void OnRecycle();
}

public class ObjectPool<T> where T : MonoBehaviour, IPoolable {
    private readonly Queue<T> _pool = new();
    private readonly T _prefab;
    private readonly Transform _parent;
    private readonly int _maxSize;

    public ObjectPool(T prefab, int initial, int max, Transform parent) {
        _prefab = prefab;
        _maxSize = max;
        _parent = parent;
        for (int i = 0; i < initial; i++)
            _pool.Enqueue(CreateNew());
    }

    public T Get() {
        T obj = _pool.Count > 0 ? _pool.Dequeue() : CreateNew();
        obj.gameObject.SetActive(true);
        obj.OnSpawn();
        return obj;
    }

    public void Return(T obj) {
        obj.OnRecycle();
        // 超上限直接 Destroy，不塞回池子（防膨胀）
        if (_pool.Count >= _maxSize)
            Object.Destroy(obj.gameObject);
        else {
            obj.gameObject.SetActive(false);
            obj.transform.SetParent(_parent);
            _pool.Enqueue(obj);
        }
    }

    T CreateNew() {
        var go = Object.Instantiate(_prefab, _parent);
        go.SetActive(false);
        return go.GetComponent<T>();
    }
}
```

    public virtual void OnBind() { }   // 订阅事件
    public virtual void OnUnbind() { } // 取消订阅
}

// 血条 Binder
public class HealthBarBinder : UIBinder {
    public Image fillImage;
    public EntityBase target;

    public override void OnBind() {
        EventBus.Subscribe<EntityHitEvent>(OnEntityHit);
    }
    public override void OnUnbind() {
        EventBus.Unsubscribe<EntityHitEvent>(OnEntityHit);
    }
    void OnEntityHit(EntityHitEvent e) {
        if (e.target != target) return;
        fillImage.fillAmount = target.CurrentHP / target.MaxHP;
    }
}

// 经验条 Binder（Lerp 插值动画）
public class ExpBarBinder : UIBinder {
    public Image fillImage;
    private float _displayed = 0f;
    private float _target = 0f;

    void Update() {
        if (!Mathf.Approximately(_displayed, _target))
            _displayed = Mathf.Lerp(_displayed, _target, 5f * Time.deltaTime);
        fillImage.fillAmount = _displayed;
    }
    void OnLevelUp(LevelUpEvent e) {
        _target = 0f; // 升级清零
    }
}

## 16. 关键设计约束（不可违反）

1. **主工程不碰业务**：所有游戏逻辑在 HotUpdate 程序集，Main 只负责启动/资源/热更加载
2. **EventBus 解耦**：系统间不直接引用，通过事件通信（受击/击杀/升级/拾取/切换武器）
3. **ModifierPipeline 唯一聚合**：伤害计算只走管道，Buff/词条/遗物都作为 IModifierProvider 注入
4. **元素与武器正交**：EnemyElementMarks 是独立组件，不依赖武器系统
5. **对象池防膨胀**：超上限直接 Destroy，不塞回池子
6. **1 格 = 1 Tile = 1 世界单位**：所有距离/半径/射程统一度量
7. **FSM 轻量化**：不用行为树，EnemyState<T> + JSON 配置化转换表即可
8. **DataService 唯一数据入口**：不绕过它直接 LoadAsset
